### Release notes

```md
## Summary

First public-ready version of `claude-skills-poui`, a Claude Code Skill focused on PO UI, Angular and TOTVS Protheus/ADVPL.

## Highlights

- Skill `poui-protheus` with anti-hallucination rules.
- Curated local reference for `po-table`.
- Minimal Angular example with typed `PoTableColumn`, `PoTableAction` and status labels.
- Protheus/ADVPL guidance for backend, permissions, auditability and performance.
- Prompts for screen analysis and PO UI screen generation.
- Contribution guide and roadmap for new components.

## Notes

This is a community and independent project. It is not officially affiliated with TOTVS, PO UI, Anthropic or Claude.

Before using generated code in production, validate it against the installed version of `@po-ui/ng-components`.
```
